## Project Objective

This project demonstrates autonomous navigation and swarm coordination of multiple TurtleBot3 robots using Webots and ROS 2.

The objective is to study multi-agent robotic systems, cooperative navigation and swarm control algorithms.

- Ubuntu 24.04
- ROS2 Humble
- Webots 2025a
- Python
- TurtleBot3

- Single TurtleBot motion
- Multi-robot simulation
