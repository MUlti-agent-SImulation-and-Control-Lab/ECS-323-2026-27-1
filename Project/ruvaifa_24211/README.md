## 1. Project Overview

This is our code for the **Robot Conga** sequential path-following algorithm, based on the paper:
> *Robot Conga: A Leader-Follower Walking Approach to Sequential Path Following in Multi-Agent Systems* (Tiwari & Nath, 2025).

Instead of relying on rigid formations or simple time-delay following, the Robot Conga approach focuses on spatial propagation:
$$s_i = s_L - i \cdot d$$
This ensures each follower robot $i$ tracks a reference state based on its specific arc-length offset ($s_i$) along a shared path. We implemented a Lyapunov-based nonlinear controller to handle the tracking. To make things more realistic, we also added velocity saturation, a singularity guard, 100 ms actuation delays, and simulated sensor noise at 15 Hz.

## 4. Demos

You can run any of the demo scripts right out of the box. They'll save their output plots to the `results/` folder.

### 4.1 Multi-Robot Conga Simulation (Main Demo)
This script simulates 4 robots (1 leader, 3 followers) maintaining a 1.0 m gap along an S-curve path. It includes the 100 ms delay and measurement noise mentioned earlier.
```bash
python src/examples/conga_demo.py
```
**What you'll get in `results/`:**
- `xy_trajectory.png`: The paths taken by the robots.
- `position_error.png`: How far off they were over time.
- `heading_error.png`: How much their heading strayed.
- `inter_robot_spacing.png`: Gap between agents (target is 1.0 m).
- `arc_length_position.png`: How they progressed along the path.

### 4.2 Straight-Line & Circle Tracking
If you just want to test a single agent tracking a simple path at $V_{\text{cmd}} = 0.10\text{ m/s}$:
```bash
python src/examples/straight_demo.py
python src/examples/circle_demo.py
```

### 4.3 Singularity Guard Test
We added a check to prevent the math from blowing up (`NaN`/`inf`) when the heading gets close to $\pm \pi/2$. You can verify that it correctly throws a `ControllerSingularityError` by running:
```bash
python src/examples/singularity_demo.py
```

We wrote 31 automated tests to make sure the math, paths, and controller behave properly.

```bash

colcon test --packages-select robot_conga --python-testing pytest
colcon test-result --verbose
```
